# VOICEVOX用ネットワーク用語ユーザー辞書

[VOICEVOX](https://voicevox.hiroshiba.jp/) 用にネットワーク用語を登録したユーザー辞書が、 `network-words.json` です。

## インポート方法

### VOICEVOX の Web インターフェースを利用する場合

1. `http://127.0.0.1:50021/setting` にアクセス
2. `ユーザー辞書のインポート`節にある `インポート` ボタンをクリック
3. `参照` ボタンで `network-words.json` を選択
4. `インポート` ボタンをクリック

### curl インターフェースを利用する場合

#### Linux の場合

```
curl -X POST "http://127.0.0.1:50021/import_user_dict?override=true" \
  -H "Content-Type: application/json" \
  -d @network-words.json
```

#### Windows (コマンドプロンプト) の場合

```
curl -X POST "http://localhost:50021/import_user_dict?override=true" -H "Content-Type: application/json" -d "@network-words.json"
```

#### Windows (Powershell) の場合

```
curl.exe -X POST "http://localhost:50021/import_user_dict?override=true" -H "Content-Type: application/json" -d "@network-words.json"
```
